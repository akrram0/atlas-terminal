Installation & Setup

Atlas Terminal is distributed as both an automated Windows installer and a standalone portable archive.

Method 1: Windows Installer (.exe)

The standard installer integrates Atlas into your Windows Start Menu, configures desktop shortcuts, and registers background delta auto-updates.

# Download the latest installer from GitHub Releases:
https://github.com/akrram0/atlas-terminal/releases/latest

Method 2: Windows Package Manager (winget)

You can install and update Atlas Terminal via the official winget manifest:

winget install akrram0.atlas-terminal

Method 3: Portable Zero-Install Archive

Extract atlas-terminal-windows-x64.zip into any folder (e.g. C:\Tools\Atlas) and run atlas-terminal.exe directly. Your configuration is stored in ~/.config/atlas/settings.json (or right next to the executable if portable.txt is present).

Developer Superpowers

Atlas Terminal is built specifically for software engineers with integrated workflows that eliminate context switching:

1. Find in Terminal (Ctrl+F)

A floating, non-intrusive macOS-style search bar that hovers cleanly over the active pane. Features live buffer highlighting across both the active screen and scrollback history, instant match navigation (Enter / Shift+Enter), a real-time match counter badge (3 of 18), and kinetic auto-scrolling to matching lines.

2. Click-to-Code: Smart File Jumps (Ctrl+Click)

Hover any compiler error, panic stack trace, or source path (e.g. src/main.rs:42:15, server.ts:108) with Ctrl held to reveal an accent highlight. Clicking it automatically resolves relative paths against the active pane's working directory and launches your preferred editor directly at the exact line and column coordinates:

  • Auto-Detect: Automatically probes for VS Code (code --goto), Cursor, or Zed on your %PATH%.
  • Configurable: Select your preferred editor (VS Code, Cursor, Zed, or System Default) in the Settings drawer under Developer & Editor.

3. Native Background Task Notifications

Never wait idly on a terminal prompt again. When a long-running build or command (such as cargo build, npm install, or docker build) finishes while Atlas Terminal is unfocused or minimized, Atlas sends a native Windows Action Center notification alert with the job duration.

The duration threshold can be configured to 5s, 10s, 30s, or 60s in Settings under Background Notifications.

Tabs & Split Panes

Atlas supports nested horizontal and vertical split layouts. Each pane maintains its own independent PTY process, working directory, and mouse capture state.

When working in a split layout, press Ctrl+Shift+M to temporarily maximize your active pane to fill the entire window without losing your multi-pane layout. Pressing it again restores your split geometry.

Modern Mouse Reporting & Hyperlinks

Atlas Terminal features full SGR mouse tracking (?1000h / ?1006h) support. Interactive TUI applications such as Lazygit, OpenCode, Neovim, and Midnight Commander respond seamlessly to mouse clicks, dragging, and wheel scrolling.

  • Selection Bypass: Hold Shift while dragging to bypass application mouse capture and select terminal text normally.
  • Interactive Hyperlinks: Press Ctrl + Click on any highlighted URL to open it immediately in your default browser.
  • Keyboard URL Picker: Press Ctrl + Shift + O to extract all visible URLs into the Command Palette and open them without touching the mouse.

WSL Linux Profiles & Terminal Forwarding

Atlas Terminal automatically inspects your Windows Subsystem for Linux installation and creates shell profiles for every registered distribution (Ubuntu, Debian, Arch, Fedora, openSUSE, Alpine).

Atlas automatically forwards TERM_PROGRAM=Atlas and TERM_PROGRAM_VERSION into WSL through WSLENV with /u flags, ensuring that Fastfetch and Linux shell prompts correctly recognize Atlas Terminal.

Themes, Settings & Configuration

Atlas Terminal features a native macOS Inset Grouped Settings window (Ctrl + ,) with visual theme cards, segmented controls, and direct links to configuration files.

Configuration Files Hub

All terminal preferences are stored in clean JSON format at ~/.config/atlas/settings.json:

  • Typefaces: Any monospace font installed on your system can be configured via "font_family": "JetBrains Mono".
  • Background Blur: Toggle translucent acrylic glass on/off in Settings. Set custom glass opacity percentage via "opacity": 0.85.
  • Custom Prompt & Shell Profiles: In Settings, click Edit $PROFILE to customize your PowerShell prompt function, Oh-My-Posh, or Starship theme.
  • Fastfetch Config: If Fastfetch is detected, Settings automatically reveals an Edit config.jsonc action to customize logo images, padding, and system specs.
  • Live Reload: Click Reload from Disk in Settings to apply manual edits from settings.json instantly without restarting.

DirectX GPUI Rendering Engine

Atlas Terminal is built in Rust using Zed's GPUI framework. Unlike legacy Win32 consoles or Electron wrappers, Atlas treats the terminal screen as a hardware-rendered DirectX scene:

  • Quad Batching: Character cells, cursor blocks, and background colors are translated into GPU instanced quads.
  • DirectX 12 Shaders: Release builds compile DirectX shaders using Microsoft's FXC shader compiler, eliminating runtime shader overhead.
  • Optimized Timer Precision: Configures high-resolution timer scheduling at startup for responsive input and smooth animation.

Kinetic Cursor & Scroll Physics

Rather than jumping instantaneously across characters or snapping line-by-line, Atlas Terminal simulates kinetic motion using critically damped spring equations: 

// Exponential approach toward target character cell:
dx = (target_x - current_x) * (1.0 - (-28.0 * dt).exp());
dy = (target_y - current_y) * (1.0 - (-28.0 * dt).exp());

When navigating within a 15-column / 10-row proximity window, the cursor glides smoothly with zero overshoot. For long jumps (clearing the screen or jumping across pages), it snaps instantly to prevent disorienting motion.

History scrolling applies momentum carryover and subpixel row interpolation, allowing buttery smooth navigation through thousands of lines of build logs at your display's full native refresh rate.

Rounded Quad Geometry & Anti-Leak Rules

Windows DWM Acrylic windows have rounded borders (14px outer radius / 13px inner radius). To prevent solid background cells from clipping or poking through the rounded corners, Atlas Terminal enforces strict geometry math in its Rust paint pipeline: 

// Cell safe padding prevents text from touching window borders:
.px(px(10.0)).py(px(10.0))

// Non-default background spans touching the window perimeter receive corner radii:
corner_radii: Corners {
    bottom_left: px(13.0),
    bottom_right: px(13.0),
}

Procedural Vector Box Drawing & Prompt Precision

Modern developer shell prompts (including Starship, Oh-My-Posh, Powerlevel10k, and WSL Arch/Ubuntu default configurations) construct multi-line prompt frames and arrows using Unicode box-drawing characters: 

╭─ user@archlinux ─ [~/workspace]
╰─> cargo test

In many terminal emulators, prompt arrows and box lines often look jagged, "painted", or break apart into disconnected pieces when zooming out. Atlas Terminal solves this root architectural cause by implementing a dedicated procedural vector engine inspired by Windows Terminal's AtlasEngine.

The Root Causes: Why Prompts Look "Painted" or Disconnect in Other Terminals

  • Font Baseline Drift vs. Cell Center: When terminals rely on font glyphs for rounded corners (╭, ╰ / U+256D..=U+257F) while procedurally drawing horizontal lines (─ / U+2500), DirectWrite/FreeType positions corners relative to font ascenders, descenders, and hinting baselines. When zooming out, fractional rounding causes the font baseline to drift away from the geometric center of the cell. The corner ends up 1 to 2 pixels higher or lower than the line, creating an ugly detached "bent hook" or gap.
  • Square Quad "Stair-Stepping": Some terminals attempt custom arcs by stamping a series of discrete axis-aligned square quads along an arc. Because axis-aligned quads cannot rotate with the curve's tangent vector, at 45° angles their corners form sharp saw-tooth steps that look like low-resolution bitmap paint.
  • Rigid Stroke Weights: Hardcoded stroke weights (e.g., fixed 2px) do not scale with font zoom. Zooming out makes lines appear disproportionately heavy, while zooming in makes them appear hairline thin.

The Atlas Procedural Vector Solution

Atlas Terminal bypasses font glyph fallback entirely for all box-drawing and corner characters (U+2500..=U+257F) and renders them procedurally directly on the DirectX GPU:

  • Dynamic Zoom-Aware Stroke Scaling: Adapting the formula from Windows Terminal's BuiltinGlyphs.cpp, line thickness scales dynamically with cell width: 
    light = max(1.0, round(cell_width / 6.0));
heavy = max(light + 1.0, light * 2.0);
    Lines remain crisp and optically balanced whether viewed at 50% or 500% zoom.
  • Hardware MSAA Cubic Bézier Arcs: Rather than stamping quads, rounded corners are constructed as continuous cubic Bézier vector paths using the optimal circle constant κ ≈ 0.55228475. The path is tessellated with Lyon and rasterized directly on the DirectX GPU with hardware multi-sample anti-aliasing (MSAA), producing silky-smooth, perfectly anti-aliased curves.
  • Exact C¹ and G¹ Tangent Continuity: Straight box lines and corner curves meet at exact cell midpoints (sy = cy + 0.5, sx = cx + 0.5). Start and end tangents match the incoming straight lines with subpixel floating-point precision, guaranteeing zero gap across adjacent terminal cells.

How We Profile

  • Cold Startup: Clocked from process invocation (CreateProcessW) until the primary window handle (HWND) is mapped and the initial swapchain frame is presented. Atlas eliminates startup delays by avoiding JIT runtimes or WinUI XAML markup loading.
  • Memory Working Set: Sampled using Windows process performance counters (WorkingSet64 and PrivateMemorySize64) after a quiescent settling delay. Even with a full hardware acrylic composition layer and vector curve tessellation caches, Atlas consumes only ~60MB.
  • Timer Precision: Standard Windows applications suffer from coarse timer resolution. Atlas optimizes system timer scheduling at startup, allowing GPUI's event loop to deliver fluid, tear-free motion with zero frame drops.
