[ 01 // getting started ]

Installation & Setup

Atlas Terminal is distributed as both an automated Windows installer and a standalone portable archive.

Method 1: Windows Installer (.exe)

The standard installer integrates Atlas into your Windows Start Menu, configures desktop shortcuts, and registers background delta auto-updates.

# Download the latest installer from GitHub Releases:
https://github.com/akrram0/atlas-terminal/releases/latest

Method 2: Windows Package Manager (winget)

You can install and update Atlas Terminal via the official winget manifest:

winget install akrram0.atlas-terminal

Method 3: Portable Zero-Install Archive

Extract atlas-terminal-windows-x64.zip into any folder (e.g. C:\Tools\Atlas) and run atlas-terminal.exe directly. Your configuration is stored in ~/.config/atlas/settings.json (or right next to the executable if portable.txt is present).

[ 03 // workflows ]

Tabs & Split Panes

Atlas supports nested horizontal and vertical split layouts. Each pane maintains its own independent PTY process, working directory, and mouse capture state.

When working in a split layout, press Ctrl+Shift+M to temporarily maximize your active pane to fill the entire window without losing your multi-pane layout. Pressing it again restores your split geometry.

[ 04 // graphics ]

Fastfetch Inline Images Setup

Atlas Terminal features native support for the iTerm2 OSC 1337 image protocol without requiring Sixel or WebViews. Fastfetch can render your high-resolution distro or custom avatar graphic directly beside system specs.

Add this to your ~/.config/fastfetch/config.jsonc:

{
  "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json",
  "logo": {
    "type": "iterm",
    "source": "/path/to/your/avatar.png",
    "width": 18,
    "height": 9,
    "padding": {
      "top": 1,
      "left": 2,
      "right": 3
    }
  },
  "modules": [
    "title",
    "separator",
    "os",
    "host",
    "kernel",
    "uptime",
    "terminal",
    "display",
    "cpu",
    "gpu",
    "memory"
  ]
}
[ 05 // linux ]

WSL Linux Profiles & Terminal Forwarding

Atlas Terminal automatically inspects your Windows Subsystem for Linux installation and creates shell profiles for every registered distribution (Ubuntu, Debian, Arch, Fedora, openSUSE, Alpine).

Atlas automatically forwards TERM_PROGRAM=Atlas and TERM_PROGRAM_VERSION into WSL through WSLENV with /u flags, ensuring that Fastfetch and Linux shell prompts correctly recognize Atlas Terminal.

[ 06 // configuration ]

Themes, Settings & Configuration

Atlas Terminal features a native macOS Inset Grouped Settings window (Ctrl + ,) with visual theme cards, segmented controls, and direct links to configuration files.

Configuration Files Hub

All terminal preferences are stored in clean JSON format at ~/.config/atlas/settings.json:

  • Typefaces: Any monospace font installed on your system can be configured via "font_family": "JetBrains Mono".
  • Background Blur: Toggle translucent acrylic glass on/off in Settings. Set custom glass opacity percentage via "opacity": 0.85.
  • Custom Prompt & Shell Profiles: In Settings, click Edit $PROFILE to customize your PowerShell prompt function, Oh-My-Posh, or Starship theme.
  • Live Reload: Click Reload from Disk in Settings to apply manual edits from settings.json instantly without restarting.
[ 07 // architecture ]

DirectX GPUI Rendering Engine

Atlas Terminal is built in Rust using Zed's GPUI framework. Unlike legacy Win32 consoles or Electron wrappers, Atlas treats the terminal screen as a hardware-rendered DirectX scene:

  • Quad Batching: Character cells, cursor blocks, and background colors are translated into GPU instanced quads.
  • DirectX 12 Shaders: Release builds compile DirectX shaders using Microsoft's FXC shader compiler, eliminating runtime shader overhead.
  • 1ms Windows Timer Precision: Calls timeBeginPeriod(1) at startup to eliminate Windows 15.6ms timer quantisation, delivering true 240Hz frame scheduling.
[ 08 // rendering ]

Rounded Quad Geometry & Anti-Leak Rules

Windows DWM Acrylic windows have rounded borders (14px outer radius / 13px inner radius). To prevent solid background cells from clipping or poking through the rounded corners, Atlas Terminal enforces strict geometry math in its Rust paint pipeline: 

// Cell safe padding prevents text from touching window borders:
.px(px(10.0)).py(px(10.0))

// Non-default background spans touching the window perimeter receive corner radii:
corner_radii: Corners {
    bottom_left: px(13.0),
    bottom_right: px(13.0),
}
