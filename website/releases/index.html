v0.1.74 Latest Stable
Published 2026-10-27

Architectural rewrite of box-drawing rendering matching Windows Terminal's AtlasEngine: dynamic zoom-aware stroke scaling, GPU anti-aliased vector paths for rounded corners, and seamless tangent continuity at any zoom level.

  • Windows Terminal AtlasEngine Builtin Architecture: Re-unified all box-drawing and rounded corners into a single procedural pipeline. Eliminates font baseline mismatch, sagging corners, and broken tangents when zooming out.
  • Dynamic Zoom-Aware Stroke Weight: Stroke widths dynamically scale with cell width (std::max(1.0f, roundf(cw / 6.0f))). When zoomed out, lines and corners scale down to crisp 1px strokes; when zoomed in, they scale up proportionally without blocky stair-stepping.
  • GPU Anti-Aliased Vector Arcs: Rounded corners (╭, ╮, ╯, ╰ / U+256D..=U+2570) are rendered via cubic Bezier vector paths with hardware MSAA on DirectX 12. Stems align precisely to the cell centerline tangents (sy = cy + 0.5, sx = cx + 0.5) and end flush at the cell boundary with zero gaps.
  • Rock-Solid Prompt Continuity: Starship, Oh-My-Posh, and Arch prompt lines (╭─ archlinux ~ and ╰─>) remain perfectly tangent and connected at every zoom level from 8pt to 36pt.
