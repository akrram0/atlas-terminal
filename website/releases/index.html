v0.2.23 Latest Stable
Published 2026-11-07

Major aesthetic overhaul and customization milestone introducing Curated Aesthetic Themes (Gruvbox, Barbie Dark & Light, Osaka Jade, Rosé Pine, Dracula), an Extensible Custom Theme System with Windows Terminal scheme compatibility, and a Zero-Script Built-in Benchmark (atlas bench).

  • Aesthetic Themes Gallery: Added Gruvbox (Dark & warm cream Light), Barbie (Synthwave cyber-pink Dark & dreamhouse pastel blush Light), Osaka Jade & Mint, Rosé Pine & Rosé Pine Dawn, and Dracula & Light — engineered for maximum eye comfort and vibrant visual personality.
  • Extensible Custom Theme Importing: Users can install and load any custom terminal theme. Atlas auto-scans ~/.config/atlas/themes/*.json on startup and live reload, with out-of-the-box support for Windows Terminal color schemes (windowsterminalthemes.dev).
  • CLI Theme Management: atlas theme list (with RGB color swatches), atlas theme install <path|url>, atlas theme export <name>, atlas theme dir, and atlas theme set.
  • Settings GUI Integration: Added an "Open Themes Folder" action button and visual custom theme badges directly in the Settings window (Ctrl + ,).
  • Built-in Zero-Script Benchmark: atlas bench reports live Win32 process memory footprint (~25 MB working set vs ~89 MB Windows Terminal), ANSI stream throughput (850+ MB/s), hardware composition latency (<1 ms), and full protocol verification.

v0.2.22 Previous Stable
Published 2026-11-07

Major milestone release introducing the Atlas Satellites Subterminal Tools Suite (atlas <cmd>), Dynamic Island Topbar HUD with OSC 1338 protocol, fluent acrylic blur and pure glass (0% opacity) rendering, and thread-safe URL handling.

  • Atlas Satellites Suite: Embedded zero-overhead developer companion tools via atlas (console subsystem) — atlas port 3000 -k (port inspector & process killer), atlas jwt (offline token decoder), atlas qr (terminal QR generator), atlas json (formatter & selector), atlas diff (side-by-side terminal diffs), and atlas hud (island notification trigger).
  • Dynamic Island Topbar HUD: High-fidelity capsule notification overlay supporting real-time update pulses, shell status changes, and custom script notifications via OSC 1338 escape sequences.
  • Fluent Acrylic Blur & Pure Glass Translucency: Completely rewritten background compositor with native DWM acrylic accent, pure 0% clear glass mode, and seamless opacity scaling.
  • Thread-Safe URL Handling: Detached background browser dispatch eliminating GPUI apartment threading conflicts on Ctrl+Click and keyboard link picker.
  • Compact Window Architecture: Calibrated 880x540 default startup bounds with automatic window dimension persistence.
