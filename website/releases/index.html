v0.1.71 Latest Stable
Published 2026-10-27

Major release featuring complete Settings overhaul, dynamic WSL distribution auto-detection, Apple SF vector action icons, Background Blur acrylic toggle, and direct configuration file integration.

  • Redesigned Action Icons: Crisp circular refresh arrow and precision 6-tooth gear with optical center balance and anti-collision hover clearance.
  • Dynamic WSL Distribution Detection: Automatically inspects the Windows registry on launch to render your exact distro's logo (Arch Linux, Ubuntu, Debian, Fedora, openSUSE, Alpine, etc.) or fallback Tux penguin.
  • Background Blur Acrylic Switch: Clean Apple-style toggle switch for Fluent glass translucency, with custom opacity percentage defined directly in settings.json.
  • Configuration & Prompt Files Hub: Instant one-click access in Settings to edit settings.json and customize your PowerShell $PROFILE (custom prompt name, Starship, and fastfetch).
  • OpenCode AI Terminal: Full compatibility and reliable execution for autonomous agent workflows.
