[ 02 // capabilities ]

Engineered for extreme performance and aesthetic rigor

Zero compromises between raw hardware responsiveness and meticulous typography.

240Hz Adaptive Frame Scheduling

Invokes timeBeginPeriod(1) at startup, bypassing the default 15.6ms OS timer. Renders at 4ms during active kinetic motion and steps down to quiescent 0% CPU idle intervals.

Fluent Acrylic Blur & Glass Translucency

Restrained Apple/macOS design language. Frameless client area with native Windows 11 DWM Acrylic glass blur, customizable opacity via settings.json, and instant GPU swapchains.

Native Inline Graphics (OSC 1337)

Direct iTerm2 image protocol integration inside the GPUI renderer. Fastfetch logos, CLI charts, and diagrams remain 1:1 anchored to their lines during scrollback and reflow.

Raycast-Style Command Palette

Press Ctrl+Shift+P or Ctrl+K to launch shell profiles, split panes, and filter on-screen hyperlinks with multi-word fuzzy search.

Dynamic WSL Distro & Brand Detection

Automatic registry detection for Arch Linux, Debian, Ubuntu, Fedora, openSUSE, and Alpine with authentic vector logos, plus standard Tux penguin fallback when WSL is absent.

Critically Damped Kinetic Scroll

Exponential decay kinematics with momentum carryover and subpixel row interpolation. Glides through massive compiler logs without jank or scroll jumps.

Procedural Vector Box & Prompt Precision

Inspired by Windows Terminal's AtlasEngine. Eliminates jagged pixel stair-stepping and baseline drift on zoom-out. Starship, Oh-My-Posh, and WSL prompts render with hardware MSAA cubic Béziers.

Floating Damped Spring Cursor

Mathematical exponential glide physics with organic breathing alpha and proximity snap thresholds. Smooth character navigation without visual lag.

Cryptographic Delta Auto-Updater

Silent background checks against GitHub Releases with conditional ETag validation and SHA-256 binary verification. Updates staged in-place in under a second.

[ 05 // faq ]

Frequently asked questions

Yes. Atlas Terminal natively runs on both 64-bit Windows 11 and Windows 10. Hardware DirectX acceleration works across modern Intel, AMD, and NVIDIA graphics. On Windows 11, it seamlessly unlocks native DWM acrylic materials.
Electron and WebView wrappers incur massive memory overhead (often 300MB+) and jittery DOM-based layout reflows. GPUI compiles directly to native machine code in Rust, uploading vertices and quads directly to DirectX shaders for instant 240Hz frame rates and ~28MB base RAM usage.
Atlas implements the iTerm2 OSC 1337 image protocol. Tools like Fastfetch, Neofetch, and custom shell scripts send base64-encoded image payloads directly via escape sequences. Atlas rasterizes the graphic into a GPUI texture and anchors it to the scrollback buffer so it stays positioned with your history.
Most terminals delegate rounded corners to font glyphs, which drift from geometric line centers during zoom-out, creating disconnected gaps. Other approaches stamp square quads that produce jagged, “painted” steps. Atlas Terminal implements Windows Terminal AtlasEngine-inspired procedural vector geometry in Rust: stroke widths scale dynamically with cell size (cw / 6.0), and corners are rendered as cubic Bézier curves with hardware MSAA. Prompts stay razor-sharp and gap-free at any zoom level.
Atlas features a silent background delta updater that polls official GitHub Releases using conditional HTTP ETags. New versions are verified with SHA-256 cryptographic signatures before prompting you to restart.
